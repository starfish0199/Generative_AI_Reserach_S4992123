**What does git clone do? What does GitHub fork do? What are the differences between git clone and GitHub fork?**
Git clone creates a local copy of a repository on your computer, allowing you to work on the project offline and make changes. It directly links to the original repository for pulling and pushing updates.
GitHub fork creates a copy of a repository under your own GitHub account. It is mainly used for contributing to other people's projects without affecting the original repository.
The main difference is that clone is a local operation, while fork is a server-side copy on GitHub. Fork is used for collaboration, while clone is used for development on your own machine.
